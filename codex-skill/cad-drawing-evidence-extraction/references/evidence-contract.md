# CAD 证据输出契约

每份图纸至少输出 `review.md`，必要时附 `table-candidates.md`、`table-candidates.csv` 及原始 JSON/TSV。所有输出位于本次显式 `-WorkRoot`、`CAD_READING_WORK_ROOT` 或默认本机 `%LOCALAPPDATA%\CadReadingToolkit\Work` 的 `analysis/` 或 `output/`，且不得位于OneDrive/同步目录；最终成果可再复制到项目输出目录。

## `review.md` 最小字段

```markdown
# 项目/图纸：<文件名>

## 输入与方法
- 原图：<相对路径>
- 导出通道：<中望 CAD API / Core Console / 视觉 / OCR>
- 原图状态：只读，未修改

## 参数
| 字段 | 值 | 原文/表格行 | 坐标 | 可信状态 |

## 技术要求
| 要求 | 原文 | 坐标 | 可信状态 |

## 质量、检验与维护
| 要求 | 原文 | 坐标 | 可信状态 |

## 数量与布置
- 参数表数量：<候选或未找到>
- 布置图逐符号核对：<已完成/未完成>

## 待人工核实/待深化
1. ...
```

## 可信状态

- `已确认`：原文和坐标可回查，且参数关系由同一表格行/列或线框边界确认。
- `候选`：已识别文本或表格，但范围、关系或图面位置仍需核对。
- `待人工核实`：图面可见但导出未能可靠确认，或符号数量未逐个统计。
- `待深化`：设计输入未提供深化图、节点、计算书或检测资料。

## 禁止自动下结论

- 参数表数量、抽检数量、检测数量和说明示例数量不能写成供货数量。
- “符合标准”或“有型式检验要求”不等于实际产品已合格。
- 不从邻近文字推断缺失型号、尺寸、材料、标准条款或图框归属。

## 阻尼器数量最小证据

数量 CSV 至少保留：

- 楼栋、楼层或连续楼层范围；
- 图面唯一实例数、展开后数量、X/Y方向及型号小计；
- 根实例句柄、块定义句柄、重复根句柄和几何句柄；
- 每个选中实例对应的 V13 可见性记录、有效图层、可见性原因及布局视口数量；
- 图面数与数量表值的差异；
- `text_instance_consistent`、`seeded_unlabeled_geometry_consistent`、`text_and_geometry_consistent` 或明确的冲突/未解析状态。

文字与几何冲突、楼栋/楼层不能唯一归属、连续楼层表达不明确或没有可靠几何种子时，不生成闭合数量。

跨视图身份全部归一仍不等于可见性闭合。只有选中实例均有相同 `instance_key`
的 V13 记录、数据库层确认可见、导出错误数为零且不存在待核验布局视口时，
才可使用 `cross_view_quantity_closed`。缺记录、隐藏实例、导出错误或布局视口
未核验时必须使用 `cross_view_identity_consistent_visibility_unverified`。

布局页和视口不得作为新设备计数来源。同一模型空间 `instance_key` 被多个布局
视口重复展示时只计一次，并保留全部视口句柄供回查。候选落入非矩形裁剪视口、
非俯视视口、关闭视口或冻结其有效图层的视口时，保持布局可见性未解决。

## V16 汇总状态

- `design_quantity_candidate_reconciled`：图面实例、楼层/型号表及可见性证据在当前图纸内部一致；
- `layout_instance_candidate_ready`：形成可计入的图面实例，但没有完成楼层/型号表调和；
- `frame_evidence_required`：阻尼器候选存在，但没有可靠图框角色；
- `manual_review_required`：图框或候选角色存在冲突，不能自动计入；
- `layout_viewport_unresolved`：语义叶子未在有效布局视口完成可见性闭合；
- `visibility_export_unresolved`：V13有对象、图层、动态属性或视口读取错误；
- `export_incomplete`：统一入口的必需导出缺失；
- `no_damper_candidate`：在当前API证据范围内未找到候选，不等同于证明图中没有阻尼器。

目录筛选的 `supporting`、`reference`、`older_revision`、`exact_duplicate`、`excluded` 和 `uncertain` 默认记录为 `not_selected`，不表示这些图纸没有阻尼器。`older_revision` 只表示文件名主体一致且明确八位日期较早，不是正式版本关系；`exact_duplicate` 只表示 SHA-256 完全相同。

## V18 内容复筛状态

- `promoted_primary`：辅助/不确定文件的实际插入可达内容中出现阻尼器语义证据，可进入完整六导出；
- `keep_supporting`：保留为跨视图候选，不直接计数；
- `reference_hit`：命中参数、总说明或目录参考内容，只在需要时调用；
- `content_negative`：本次 API 可读范围未命中，不能写成“图中没有阻尼器”；
- `content_unresolved`：导出失败、代理对象或逐对象跳过导致判断不完整。

`V18目录内容复筛.md/csv/json` 必须保留原V17分类、内容决策、命中字段、
指纹文件路径、导出状态和 `absence_proven=false`。V18只决定是否升级文件，
不形成设备数量；升级文件仍须经过图框、实例、方向、布局可见性和跨视图物理
身份归一。不同DWG的单图数量不得直接相加。

## V19 跨 DWG 证据组状态

- `primary_layout_missing`：同一楼栋/楼层范围没有可计数结构平面或阻尼器专项布置主视图；
- `multiple_structural_primary_views` / `multiple_layout_primary_views`：主视图不唯一，不自动选择；
- `primary_axis_evidence_missing`：主视图未形成每栋至少三个数字轴、两个字母轴的可靠轴网；
- `single_primary_device_location_complete`：只有主视图，但单栋明确楼层、轴间位置、主视图实例和世界坐标均已形成完整设备定位；
- `single_primary_device_location_unresolved`：主视图至少一个设备未落入可靠轴间，或无多栋共用证据却同时落入多套楼栋轴网；
- `single_primary_location_visibility_unverified`：单主视图定位字段完整，但数据库/布局可见性证据仍有缺口；
- `device_location_floor_scope_unresolved`：楼层不能安全分配到楼栋；多栋共用图不得自动把同一平面乘到所有楼栋；
- `device_location_completeness_failed`：定位字段缺失或设备ID重复，禁止形成完整定位结论；
- `cross_view_identity_unresolved`：V12已执行，但至少一个辅助视图实例无法映射到主视图；
- `cross_view_identity_consistent_visibility_unverified`：物理身份一致，可见性仍有缺口；
- `cross_view_quantity_closed`：V12物理身份和V13数据库可见性在当前API范围内闭合。

V19 组表必须保留楼栋/楼层范围、主来源、辅助来源、调用清单、V12状态和未解决
原因。文件名有明确楼栋时，其范围优先于块内可能与型号/轴号混淆的文字；文件名
无楼栋时才回退到行内/块内证据。任何安全停止不得改写为“未发现阻尼器”。

## V21 阻尼器定位总表

V21 每条设备记录必须至少保留：唯一总表ID、局部物理设备ID、楼栋、楼层、
数字轴间及相对比例、字母轴间及相对比例、主来源、主图框、主实例键、主视图
世界坐标、楼层展开证据和定位状态。缺任一必填字段、总表ID重复、证据组未闭合、
范围未分组或载入失败时，总状态不得为 `device_location_registry_complete`。

单栋且楼层范围明确时，可从证据组范围展开楼层。多栋共用平面只有
`shared_building_standard_floor_consistent` 证据覆盖对应楼栋时，才允许同一
主实例映射到多栋及逐栋展开；否则进入 `V21阻尼器定位未决.csv`。

V22 可用基础几何补充不规则轴网，但必须同时保留几何来源和定位方法：

- 旋转/扇形直轴必须由同一轴号的两个远端文字位置确定，设备须唯一落入相邻
  两轴相向半平面形成的条带或扇区；
- 弧轴必须由轴号与圆弧端点唯一关联，至少两条圆弧共圆心、过渡半径方向一致，
  且每条圆弧存在相接的切向直线延伸；
- 圆弧区设备须落在圆弧有效角域，切线区设备须落在已导出的直线长度范围；
- 最外轴外侧不超过相邻轴距 25% 的近邻可记录为 `最后轴>OUT@比例`，`OUT`
  不是新增轴号；超过范围不得外推；
- 匹配不唯一、缺圆弧采样、缺共同圆心、缺切向延伸、多扇区同时命中或设备超出
  有效几何范围时必须保留未决。

任何不满足上述条件的不规则、旋转、弧形轴网，或仅凭轴号文字坐标不足以形成
可靠轴间时，均不得按最近轴号硬配。

## V23 几何定位证据抽查包

V23 对V21/V22已经形成的设备定位重新计算，不得直接复写原定位结果。每个物理
模板至少保留：

- 主实例键、世界坐标、楼栋、轴间和楼层展开设备列表；
- 两侧轴号文字句柄；
- 旋转/扇形直轴的最近平行轴线实体句柄；
- 弧轴的圆弧句柄、切向延伸句柄、轴号—圆弧匹配距离、共同圆心及当前有效区域；
- 原定位与重算结果的一致性；
- 每模板一张局部SVG及离线HTML索引。

同一模板跨多个楼层只生成一张SVG，逐台CSV仍须保留每个楼层设备。缺轴号句柄、
缺直轴/圆弧/延伸实体句柄、匹配距离缺失、重算轴间或比例不一致、设备不再唯一
落入轴间时使用`evidence_trace_unresolved`。SVG只是API世界坐标证据的局部
表达，不是DWG原图渲染、打印效果或视觉验收。V23不得提升V19/V21的数量、
可见性、合同、供货或生产状态；存在未进入定位的V19证据组时仍须单列。

## V24 风险分层抽样与中望回查

V24必须保留全量风险表和被抽中任务表，并采用以下边界：

- P0为证据链/跨视图映射未闭合；P1为OUT、弧形轴网、上游未闭合、
  极靠近轴线或高偏差，P0/P1全部复核；
- P2为旋转/扇形直轴、较大跨视图比例偏差或靠近边界，按楼栋分层抽样；
- P3为普通正交轴网低风险项，按楼栋少量抽样；
- 未形成逐台坐标的V19证据组必须单列，不能用SVG抽样替代；
- AI优先读取`V24AI轻量抽查清单.json`，只在抽中任务需要时读取对应SVG；
- 中望回查LISP只能自动打开非OneDrive目录中已存在的DWG分析副本，并以只读
  方式打开；原图、同步目录文件、缺失副本或当前图名不一致时必须安全停止；
- LISP只允许缩放和临时选择集高亮，不得保存或修改DWG。

任何“候选已调和”状态仍不是合同供货或生产放行数量。
