# CAD 图纸证据提取

先读取 [evidence-contract.md](references/evidence-contract.md) 与 [environment-routing.md](references/environment-routing.md)。本技能把 CAD 当作可回查的证据源：每个结论保留原文、坐标、实体来源和可信状态。

新窗口、换电脑或不确定当前Skill版本时，先读取[session-bootstrap.md](references/session-bootstrap.md)，并运行`scripts/检查CAD工具包会话.ps1`。后续路径只使用Doctor返回的`toolkit_root`；`skill_sync=drifted`或`overall_status=blocked`时不得声称当前窗口与仓库/其他窗口等价。

## 适用范围与边界

- 适用于 DWG、DXF 或 CAD 导出的 JSON/TSV，寻找设计说明、材料、型号、性能参数、技术/质量/检验条款和表格数据。
- 原始 DWG 只读：禁止保存、转换、覆盖、移动或批量打印原图。
- 文字在块内时，优先使用能递归展开块定义的 CAD API；顶层 TEXT/MTEXT 清单不完整时不得声称“图中没有”。
- 不从相邻文字拼接出缺失参数；不把参数表、检测表或注释数量当成供货数量。

## V18 统一入口、V17 分层与内容复筛

项目目录优先运行 `scripts/运行CAD阻尼器数量核对V18.ps1`。它先调用 V16
的 `-RouteOnly` 得到 V17 文件名分层，再只对 `supporting` 与 `uncertain`
执行轻量 `CADPREFILTEREXPORT18` 内容指纹。指纹只递归模型/布局中实际插入
可达的块定义，未使用块库不参与判断；依据可回查的文字、块、图层、实体类型、
代理对象和跳过对象证据输出：

- `promoted_primary`：实际内容出现阻尼器语义，升级进入完整六导出；
- `keep_supporting`：保留为跨视图候选，不自动计数；
- `reference_hit`：只在参数或范围缺失时调用；
- `content_negative`：本次 API 可读范围未命中，不等于证明图中没有；
- `content_unresolved`：导出失败、代理对象或跳过对象使判断不完整，必须复核。

可先加 `-ContentScanOnly` 只生成 `V18目录内容复筛.md/csv/json`。报告必须保留
`absence_proven=false`。默认完整流程把 V17 的 `selected` 与 V18 的
`promoted_primary` 合并后交给 V16；不得把升级文件的单图数量直接相加，
完整流程随后由 V19 自动按楼栋与楼层组织证据组，并调用 V12 执行跨视图
物理身份归一和可见性核对。

单个用户明确指定的 DWG 也可直接运行 `scripts/运行CAD阻尼器数量核对V16.ps1`，
输入单张 DWG 或项目目录。可显式传入目标电脑的中望安装目录；未传时必须先调用
`scripts/zwcad/发现CAD安装.ps1 -Vendor ZWCAD -RequireCurrentBackend`，不得复用
另一台电脑的固定路径。脚本应：

1. 把主流程 DWG 复制到显式 `-WorkRoot`、环境变量 `CAD_READING_WORK_ROOT` 或本机 `%LOCALAPPDATA%\CadReadingToolkit\Work`，核对原图与副本 SHA-256；工作目录不得位于 OneDrive/同步目录；
2. 在工作目录本机编译 V5/V6/V7/V10/V13，不携带或复用其他电脑的 DLL；
3. 通过独立中望 COM 会话只读导出，关闭时不保存；
4. 自动执行图框、实例、方向和布局视口分析；
5. 输出 `V16运行汇总.md/csv/json`，保留每张图的成功状态或安全停止原因。

V16 目录首次运行可加 `-RouteOnly`，只检查专业、图纸角色和文件名日期版本，不启动 CAD、复制 DWG 或生成数量。默认只把 `selected` 主图送入数量流程；V18通过内容指纹决定哪些 `supporting/uncertain` 可以升级。`reference` 目录/说明、`older_revision` 文件名较早日期和 `exact_duplicate` 哈希相同副本仍保留但不自动处理。用户指定目录顶层的“项目名+八位日期”DWG可作为项目包候选；同文件族默认取最新日期，同日期同 SHA-256 只取一个。文件名日期只用于筛选候选，不是正式版本证明。不得把未形成 `promoted_primary` 证据的 `uncertain` 文件自动送入数量主流程。图框面积无可靠断层、块容器跨两张
图纸或数量证据不闭合时，保持 `frame_evidence_required` 或
`manual_review_required`。

## 单图Agent自动后端

用`scripts/运行CAD只读自动后端.ps1`处理单张DWG时，顺序固定为：

1. ACadSharp先生成轻量候选；
2. 有视口、代理/未支持实体、MINSERT、非均匀缩放、缺Handle或遍历问题等关键
   未决项时，先检查并运行中望CAD；
3. 中望未安装、API不可用或执行失败时，再按AutoCAD 2023、2020、2018、2014
   检查64位宿主；
4. 2014只接受AC1027及更早DWG；未知或超限格式不得打开宿主或自动转换；
5. 所有后端均不能闭合时安全停止。

不得把不同后端的证据静默合并。必须校验`cad-backend-route.json`，保留
`absence_proven=false`。AutoCAD构建只引用本机Autodesk程序集，仅接受64位R24.2、
R23.1、R22.0、R19.1，并保留源DWG版本与宿主上限；
字体/实体外包框、纸空间整体视口相机值和运行时视口编号只作诊断。

## V20 无人值守中望执行

V16 与 V18 必须经 `scripts/zwcad/中望COM隔离批量只读导出V20.ps1`
调用中望，不再直接复用一个长时间运行的 CAD 会话。运行前：

1. 确认 Windows 已安装并注册可用的中望 CAD COM/.NET API；
2. 使用显式路径或自动发现的该电脑中望安装目录，确认 `fonts/HZTXT.SHX` 与
   `fonts/simplex.shx` 存在；
3. 关闭用户正在操作的中望 CAD。默认检测到现有 `ZWCAD` 进程就安全停止，
   不得在无人值守流程中复用或终止用户会话；
4. 把执行日志、字体策略、任务 JSON 和可重建 DLL 保存在非同步工作目录。

V18/V16正式数量管线仍仅使用中望。单图Agent路由的AutoCAD 2023 R24.2已完成
实机只读字段回归；2020 R23.1、2018 R22.0、2014 R19.1已完成源码适配和版本门禁，
但在对应真实宿主回归前不得表述为已验证等价。其他版本和32位宿主不在范围。

基础模型没有多模态能力时，可以配置独立多模态模型辅助V24高风险ROI复核；密钥只从
环境变量读取，视觉输出不能改变正式证据状态。本技能不确认梁高或安装净空；下游在
完全无多模态条件下判读梁尺寸时可靠性较低，必须只保留候选/资料不足并人工复核。

V20 为本次批处理临时设置：

- `FONTALT=HZTXT.SHX`；
- 任务本地 FMP 把 `sft/sft.shx` 映射到 `simplex.shx`，把宋体、黑体、
  仿宋、楷体及其 `.shx` 形式映射到 `HZTXT.SHX`；
- `FILEDIA=0`、`CMDDIA=0`。

每张 DWG 在独立 Windows PowerShell/CAD 进程中运行；超过单图时限时只终止
本轮新建的进程，记录 `timeout` 后继续下一张。配置变更前写入
`%LOCALAPPDATA%\CadReadingToolkit\v20-font-recovery.json`；正常结束时立即
恢复，整批父进程被外部强杀时由下一次V20启动前恢复。字体替代只用于避免缺字体
提示阻塞和取得 API 证据；字宽、字形、排版或特殊符号可能变化，不能据此验收
视觉出图。字体文件缺失、恢复账本损坏、配置恢复失败、导出不完整或代理对象
不可读时必须安全停止。

## 工作流

1. 在明确的本机非同步临时目录建立可删除的工作目录，记录输入、CAD 软件/版本和导出通道。当前电脑优先显式使用 `G:\CodexWork`；跨电脑使用 `-WorkRoot`、`CAD_READING_WORK_ROOT` 或默认 `%LOCALAPPDATA%\CadReadingToolkit\Work`，不得把 DLL、缓存或运行证据写入 OneDrive。
2. 多专业项目先按目录和图签路由，再由V18对辅助/不确定结构图做内容指纹复筛：结构图为阻尼器数量主输入；建筑图只在楼栋、楼层、房间或墙体定位有疑问时复核；暖通、给排水、电气、弱电等默认排除，不因文件数量多而逐份打开。按 [environment-routing.md](references/environment-routing.md) 选择通道：中望 .NET 递归 JSON 优先处理块内文字；Core Console/AutoLISP 适合标准实体批量 TSV；仅在图框、符号逐个数量、代理对象或复杂表格不确定时打开 CAD 视觉核对。
3. 导出文字后，保留 `text`、世界坐标、handle、source、space、layer、block_path；清洗 MTEXT 格式码只用于检索，原始字段不得丢失。
4. 先运行 `scripts/识别CAD文字表格.py` 找表头锚点和文字表格候选。TSV 的宽候选只能作为线索；有几何线段时再运行 `scripts/识别CAD线框表格.py` 用封闭线框精确切表。
5. 标准阻尼器布置先运行 `scripts/识别阻尼器实例并计数.py`：用 V6 唯一实例路径计数，并传入可靠的 `--frames` 与 `--frame-texts` 区分阻尼器专项图、结构平面、梁、柱、剪力墙、板、图例、说明和大样。整层布置若是含阻尼器语义的父容器，单台设备又是无文字叶子块，只在“当前块与直接父块均有阻尼器语义、叶子无子实例、同父至少两个叶子同构、叶子面积不超过父块 5%、父子均非带尺寸大样”同时成立时计为叶子设备。块名含阻尼器本身不足以计数。
6. 同图框内相同块名、相同几何签名和相同世界边界的完全重叠实例只计一次，并保留所有句柄路径；只有坐标接近、块名相同或表格合计相同不得去重。结合 V5 楼层标题和 V7 逐位置方向，按“楼栋 + 楼层范围 + 块定义/世界位置”去除重复展示并展开连续楼层。缺少图框角色证据而返回 `candidate_needs_frame` 是安全停止，不得降低阈值强行计数。
7. 多栋共用标准层图时，必须先从图名提取明确楼栋集合，再把API识别的每栋每层模板位置与数量表逐层 X/Y 合计核对；只有逐层数量、适用楼层和表内合计全部一致才按楼栋数与楼层数展开。数量表只验证和展开已识别模板，不得补齐图面漏识别。
8. 梁、柱、剪力墙、板图中的阻尼器表达先登记为跨视图候选，不与结构平面或专项布置图相加。V18完整流程自动调用 `scripts/组织跨DWG阻尼器证据组V19.py`：优先使用文件名中明确的楼栋范围，行内/块内范围仅用于补缺；按楼栋集合与楼层范围分组，要求唯一可计数结构平面/阻尼器布置主视图，并要求主视图形成每栋至少三个数字轴、两个字母轴。轴号可为 `楼栋-轴号`、单轴号，或同一图框内重复出现的 `命名空间-轴号`；后两类只有在证据组唯一楼栋时才归一，多个楼栋时安全停止。复合楼栋号如 `3-7#` 必须作为一个楼栋标识，不能拆成3#和7#。满足前置条件后调用 `scripts/跨视图阻尼器物理设备归一.py`；即使证据组只有主视图，也必须运行定位归一并生成V21总表，不能因“无需跨视图”而跳过。正交轴网优先使用每栋独立的数字/字母轴间相对位置；V22在清单存在 `primitive_geometry_json` 时，可用同一轴号两端文字建立旋转或扇形直轴，并把唯一匹配、共圆心且具有切向直线延伸的字母圆弧组成弧轴家族。设备只有唯一落入直轴条带/扇区或弧轴有效角域/切线长度范围时才定位。最外轴外侧不超过相邻轴距25%的近邻可写成 `最后轴>OUT@比例`，不得虚构下一轴；超过范围、缺共同圆心、缺切向延伸、轴号—圆弧匹配不唯一或多扇区同时命中时必须未决。V19随后自动调用V23，把已定位模板重算为轴号文字句柄、直线/圆弧/切向延伸实体句柄、匹配距离、有效几何区域和局部SVG；V23只提升可解释性，不得改变V19数量或可见性状态。没有可靠轴网时只允许用语义父容器内归一化局部坐标匹配到已识别主视图。单栋明确楼层可展开；多栋共用图只有存在逐栋楼层调和证据时才允许一实例映射到多栋并展开，否则输出未决，禁止自动乘算。存在布局视口时再运行 `scripts/分析布局视口阻尼器可见性.py`。布局或视口不是新设备；同一模型 `instance_key` 在多个视口重复展示仍只计一次。任一跨视图出现未归一时输出 `cross_view_identity_unresolved`；主视图实例未落入轴间或无证据地同时落入多套轴网时输出定位未决；可见性记录缺失、选中实例隐藏、导出有错误或布局视口未核验时停在未验证状态。不得用数量表或布局页数量补齐。
V23生成后自动调用V24。V24把证据未决、OUT、圆弧/切向延伸、上游未闭合和高偏差列为P0/P1并全部复核；旋转/扇形直轴、较大跨视图比例偏差及靠近边界列为P2，普通正交轴网列为P3，P2/P3按楼栋确定性分层抽样。AI优先读取轻量清单，只按任务读取对应SVG。中望LISP只能自动打开非OneDrive目录中已存在的DWG分析副本；原图、缺失副本或当前图名不一致时安全停止。V24不得改变V19/V21/V23状态。

9. 同一 DWG 含多楼栋、完全重叠根块或无文字同构符号时，增加 V10 基础几何导出并运行 `scripts/调和多楼栋阻尼器布置.py`。只从同图带设备文字的实例建立几何种子；文字与几何同时命中只计一次。任一楼栋/楼层归属、方向、去重或文字—几何数量冲突时安全停止。
10. 参数和布置分处不同 DWG 时，运行 `scripts/关联阻尼器参数与楼层布置.py`；只有布置图图签楼栋与总说明楼栋行一致、且型号一致时才确认关联。文件名相似或出现相同型号均不足以单独关联。
11. 数量输出同时列出图面实例数、楼层展开数、型号/X/Y小计、数量表值、差异、根/重复/几何句柄和证据状态。无法证明“一标注对应一台”时只报告设计布置数量候选。

## 可复用脚本

- `scripts/生成图纸文字索引.py`：读取图框候选和文字归属CSV，按显式参数生成逐图关键词、标题候选、长MTEXT预览、句柄和坐标索引；未归属文字保留计数但不混入逐图统计。
- `scripts/识别CAD文字表格.py`：输入 TSV 或中望递归 JSON，输出表头邻域候选；JSON 会收紧连续多列行带，TSV 不做该收紧。
- `scripts/导出CAD表格几何.lsp`：只读导出 TEXT、MTEXT、LINE 端点和 LWPOLYLINE 范围，供标准实体与线框表格流程使用。
- `scripts/识别CAD线框表格.py`：从表头锚点与 LINE/退化 LWPOLYLINE 重建闭合表格边界，只采纳框内文字。
- `scripts/识别阻尼器实例并计数.py`：读取 V6 块实例，并可结合 V5/V7 识别逐位置数量、方向、共用楼层和相邻图纸重复展示。
- `scripts/调和多楼栋阻尼器布置.py`：结合 V5/V6/V7/V10 识别多楼栋数量、世界坐标指纹重复、连续楼层和带文字种子匹配的无文字同构符号。
- `scripts/关联阻尼器参数与楼层布置.py`：读取楼层去重 CSV、布置图 V5 图签文字和总说明线框单元格 CSV，输出跨 DWG 楼栋—型号—参数关联。
- `scripts/跨视图阻尼器物理设备归一.py`：读取单主视图或多视图实例候选、图框文字、楼栋/楼层范围、可选 V10.1 基础几何和 V13 JSON，输出逐出现记录、楼栋物理模板和按楼层展开的物理设备；支持正交轴、旋转/扇形直轴及“同心圆弧+切向延伸”弧轴，每条设备保留定位方法、楼栋、楼层、X/Y轴间及比例、主视图实例和世界坐标。
- `scripts/组织跨DWG阻尼器证据组V19.py`：消费 V18/V16 结果，按楼栋、楼层和视图角色自动组织主视图与梁/柱/墙/板辅助视图，把对应的 `cad_primitive_export_v10.json` 写入 V12 清单并执行跨视图归一；同时输出 `V21阻尼器定位总表.csv/json/md` 与未决表，并自动调用V23生成已定位模板的人工抽查包。范围、轴网、楼层分配或定位完整性不足时安全停止。

## 升级与交接

- 代理对象、字体替代导致的不可读内容、实体导出与图像矛盾、图框归属不确定、符号数量或工程结论：保留证据并要求人工/CAD 视觉核查。
- 需要隔震支座专有复核时，继续使用 `$isolation-bearing-drawing-review`；它负责型号、系列化、连接、支墩和检验规则，本技能只提供通用证据通道。
